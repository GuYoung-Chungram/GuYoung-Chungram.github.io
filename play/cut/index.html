AI 편집 도우미 사용법
1. 연결 — 설정 → “AI 연결”에서 서비스(Claude · ChatGPT · Gemini)를 고르고 내 API 키를 넣은 뒤 연결 테스트를 눌러요.
2. 편집 화면에서 AI 버튼 — 말로 부탁하면 타임라인이 바로 바뀌어요. 마음에 안 들면 실행 취소 한 번으로 돌아가요.
예시
  • “모든 클립의 앞 0.5초를 잘라줘”
  • “두 번째 클립을 맨 뒤로 보내줘”
  • “이미지는 전부 3초씩만 보여줘”
  • “3번 클립을 2.5초 지점에서 나눠줘”
  • “프로젝트 이름을 ‘3주차 수업’으로 바꾸고 화면을 꽉 채워줘”
  • “720p MP4로 내보낼 준비해줘”
개인정보 — AI에게는 파일 이름·길이·클립 순서 같은 편집 정보 글자만 전송돼요. 영상·사진·소리 자체는 절대 전송되지 않아요. API 키는 이 기기 브라우저에만 저장돼요. 이용료는 내 API 계정에서 나가고, 키는 다른 사람과 공유하지 마세요.
