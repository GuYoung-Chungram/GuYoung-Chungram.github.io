데이터 전처리툴 v1.0

엑셀·CSV 파일을 정책분석 마스터가 읽을 수 있는 정제본으로 바꿔 줍니다. 이 도구는 네트워크를 사용하지 않습니다.
● 네트워크 전송 0건 ● 파일은 브라우저 메모리에서만 처리 ● 외부 라이브러리 0개 확인 방법 — F12를 눌러 Network 탭을 열어 둔 채 전 과정을 진행해 보셔도 요청이 한 건도 잡히지 않습니다.

파일 불러오기

CSV 또는 XLSX 파일을 올려 주세요. 인코딩(UTF-8·EUC-KR)은 자동으로 판별합니다.

📂 파일을 여기에 끌어놓거나 클릭해서 선택해 주세요
.csv · .xlsx · .xls(xlsx 형식만) — 최대 20MB 권장

원본 미리보기

가공하기 전 원본 그대로의 모습입니다. 맨 위 몇 줄이 제목이나 설명이라면, 다음 단계에서 열 이름이 들어 있는 행을 지정하시면 됩니다.

헤더 행 지정

열 이름이 들어 있는 행을 골라 주세요. 자동으로 추정한 값이 맞다면 그대로 두셔도 됩니다.

진단 요약

이 표는 불러온 파일의 주요 요소를 정리한 결과입니다.

발견된 문제

    열별 진단

    열마다 추론된 타입과 결측률, 실제 값 예시를 보여 드립니다. 경고가 붙은 열은 3단계에서 손보시면 됩니다.

    행 정리

    분석을 방해하는 행을 걸러 냅니다. 소계·합계 행이 섞인 채로 평균을 내면 값이 두 배로 부풀어 오르니 확인해 주세요.

    열 정리

    사용하실 열만 남기고, 이름을 짧게 바꾸고, 타입을 정하는 단계입니다. 단위 접미어(명·시간·원·%)와 천 단위 콤마는 자동으로 떼어 냅니다.

    정제 결과 미리보기

    개인정보 처리

    이 단계를 거친 데이터만 도구 밖으로 내보낼 수 있습니다. 원본 값은 파일로 저장하지 않는 한 어디에도 남지 않습니다.

    어떻게 고르면 될까요? 분석에 필요 없는 식별자라면 열 삭제가 가장 안전합니다. 같은 사람을 세어야 한다면(재방문 횟수 등) 가명화를 골라 주세요. 가명화는 매핑표가 있으면 되돌릴 수 있으니, 매핑표를 함께 내보낼지는 신중히 결정하시는 편이 좋습니다.

    처리 결과

    데이터 카탈로그

    보고서에서 가장 먼저 문제가 되는 부분이 출처와 기준시점입니다. 여기에 적어 두시면 정책분석 마스터가 보고서 각주로 자동 인용해 드립니다.

    집계단위가 다른 데이터를 나란히 비교하면 결론이 뒤집힐 수 있습니다.

    처리 이력

    지금까지의 처리 과정을 순서대로 기록해 둔 것입니다. 정제본에 함께 담기므로, 나중에 "이 숫자가 어디서 나왔는지" 물어보실 때 그대로 답이 됩니다.

    내보내기

    여기서 내려받은 정제본 JSON이 정책분석 마스터(B)의 입력 파일이 됩니다.
