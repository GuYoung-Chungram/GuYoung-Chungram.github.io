01 · 설치 가이드

Claude Code가 이미 켜져 있는지부터 확인합니다. 이 넷 중 하나라도 안 되어 있으면 다음 단계로 못 넘어갑니다.

STEP 01 · 사전 확인
  • 터미널에 claude --version 입력 — 버전 번호가 뜨면 통과
  • Claude 계정 로그인·구독 확인 (Claude Pro면 충분)
  • 내 PC에 프로그램 설치 권한이 있는지 확인 — 막혀 있으면 개인 노트북 지참
  • 터미널(윈도우: PowerShell, CMD 아님 / 맥: 터미널) 열 수 있는지 확인
  • 터미널에 git --version 입력 — 버전이 안 뜨면 Git 설치 필요 (특히 Windows, 아래 STEP 02에서 설치)
STEP 02 · Claude Code 설치

아직 없다면 터미널에 한 줄만 붙여넣으면 끝납니다. 대부분 Windows이니 아래 Windows 버튼을 먼저 확인하세요. 맥·윈도우 버튼이 따로 있으니 내 OS에 맞는 것만 눌러 복사하세요.

🪟 Windows (PowerShell, 반드시 CMD 아님)

① Git 설치 (Windows 필수 — 없으면 로컬 세션 실행 안 됨)

winget install --id Git.Git -e --source winget
Claude Code 데스크톱 앱을 쓰고 있다면, Git 설치 후 앱을 완전히 껐다가 다시 켜야 Git을 인식합니다.

② Claude Code 설치

irm https://claude.ai/install.ps1 | iex
🍎 macOS
curl -fsSL https://claude.ai/install.sh | bash
설치 명령 실행이 끝났으면 터미널 창을 완전히 닫았다가 새로 여세요. 열려있던 창에는 설치 경로(PATH)가 바로 반영되지 않아 claude --version이 안 먹힐 수 있습니다.

02 · 비기닝 키트 설치

STEP 00 · 실습키트 다운로드

아래 링크에서 실습키트 압축파일을 내려받아 압축을 풀어두세요. 압축 도구에 따라 폴더가 한 겹 더 감싸져 나올 수 있으니, skills 폴더가 직접 보이는 위치까지 들어간 다음 그 자리에서 터미널을 열어야 아래 ①~⑤ 명령이 정상 동작합니다.

📂 구글 드라이브에서 실습키트 받기

드라이브 페이지가 열리면 폴더를 더블클릭해서 들어가지 말고, 폴더 위에 마우스를 올린 뒤 우측의 점 3개(⋮) 아이콘 클릭 → 다운로드 버튼을 눌러야 폴더 전체가 압축파일로 받아집니다.

03 · 데이터 정리 (1단계 — AI 사용 안 함)

이 단계에서는 Claude Code를 쓰지 않습니다. 브라우저에서 파일만 올리면 자동으로 정리되고, 인터넷으로 아무것도 전송되지 않습니다. 개인정보(이름·연락처 등)는 여기서 자동으로 가려집니다.

내 데이터로 하기
  • ① 파일 올리기 데이터전처리툴.html을 열고 내 부서 엑셀/CSV를 올립니다
  • ② 결측·중복 자동 정리 빈 값, 소계행, 중복행을 기계가 셉니다 — AI 판단 없음
  • ③ 개인정보 확인 이름·연락처 등이 자동 표시되면 눈으로 한 번 확인합니다
  • ④ 카탈로그 채우기 데이터셋명·출처·기준시점 4칸을 반드시 채웁니다 — 비우면 2단계에서 보고서 각주가 안 만들어집니다
  • ⑤ 정제본 JSON 내려받기 이 파일을 다음 단계(04)에서 씁니다
🗂 데이터 전처리툴 열기

폴더를 따로 찾지 않아도 됩니다 — 이 버튼이 허브 안에서 바로 열어줍니다.

내 데이터가 없거나 시간이 부족하면

아래 샘플 정제본을 바로 받아서 04단계부터 시작하세요. 60분 걸리는 ①~⑤ 과정을 건너뜁니다.

⬇ 공공서비스 만족도 (60행) ⬇ 강의문의 응답 (29행)
두 샘플 모두 개인정보 처리(가명화) 완료된 정제본입니다.

04 · 내 프롬프트 만들기

2단계 · 여기서 Claude Code를 씁니다

정책분석마스터.html은 나만의 정책분석 자동화 페이지를 구축하기 위해 뼈대가 될 수 있는 도구입니다. 지금 어떤 모습인지 먼저 열어보고 밑그림을 파악한 다음, 내 의사결정 질문에 맞게 고쳐 씁니다. 아래 두 가지만 채우면 Claude Code에 붙여넣을 프롬프트가 자동으로 만들어집니다. 이 뼈대는 1~9단계 전체 흐름과 «전체 실행» 버튼, 2단계의 «Claude로 공공데이터 찾아오기»(claude.ai 채팅, 무료 계정도 가능)까지 갖추고 있습니다 — 다만 오늘 수업에서 실습으로 다루는 범위는 여전히 1~4단계입니다.

🔍 초안(정책분석마스터.html) 미리보기
1·2·3단계 — 정의·데이터·현황 필수
항상 포함됩니다. 의사결정 질문을 고정하지 않으면 나머지가 흔들립니다
4단계 — 문제 진단 권장
AI 브릿지 모드를 처음 체험하는 단계입니다 (05번 참고)
5단계 — 정책 사례 선택
외부 사례 조사가 필요해 시간이 오래 걸립니다 — 시간이 남을 때만
6단계 — 대안 비교 선택
이미 만들어진 슬라이더라 5분 데모로 대체해도 됩니다. 7~9단계(재원·리스크·보고서)는 오늘 다루지 않지만, «전체 실행» 버튼으로 수업 후 이어서 자동 진행해볼 수 있습니다
Claude Code에 그대로 붙여넣으세요
← 왼쪽에서 ① 의사결정 질문과 ② 단계를 고른 뒤 "내 프롬프트 만들기 →"를 누르면 여기에 프롬프트가 만들어집니다.

05 · AI 연결 방식 — 왜 오늘은 "브릿지"로만 하나요

정책분석마스터.html의 4단계(문제 진단)는 AI에 연결하는 방법이 두 가지입니다. 둘 다 알아두면 나중에 내 업무에 맞게 다르게 설계할 수 있습니다.

기준🔗 브릿지 (복사·붙여넣기)🔌 API 직접 연동
준비물이미 쓰는 Claude 계정만 있으면 끝API 키를 별도로 발급받아 입력해야 함
세종청사 내부망문제 없음 — 브라우저 밖으로 안 나감외부망이 막혀 있으면 아예 작동하지 않음
비용·토큰이미 내는 구독료 안에서 해결, 추가 과금 0원부를 때마다 별도 토큰 비용 발생
속도복사 → 붙여넣기 → 결과 다시 붙여넣기, 수작업버튼 한 번으로 자동 완료
안전 확인보내기 전에 내용을 사람이 직접 봄앱이 알아서 보내서 볼 기회가 적음
오늘 수업✅ 기본값 — 전원 이 방식개념만 소개, 실습은 안 함
오늘은 전원 브릿지 모드로 통일합니다. 이유 셋 — 세종청사 내부망에서도 100% 동작하고, 추가 비용이 0원이고, AI에게 무엇을 보내는지 직접 눈으로 보고 배우는 쪽이 "바이브코딩을 이해하는 것"이라는 오늘 수업의 목적에 더 맞기 때문입니다.
그럼 API는 언제 쓰나요? 오늘 만든 도구를 실제 업무에 정착시켜 여러 데이터셋을 반복적으로, 자동으로 처리하고 싶어질 때입니다. 그때는 부서 차원의 API 키 발급과 보안심의를 먼저 검토한 뒤 전환을 고려하세요. 오늘의 선택이 전부가 아니라, 상황에 따라 설계를 바꿀 수 있다는 것이 핵심입니다.

위 04번 상단의 "안전 문구 자동으로 붙이기"를 켜두면, 여기 카드를 복사할 때도 "기존 코드는 건드리지 말고 최소한만 바꿔줘" 문장이 자동으로 따라붙습니다.

07 · 완료 체크 · 발표 준비

이 넷을 통과하면 오늘의 결과물이 완성된 것입니다.

확인 4단계
  • 콘솔 에러 0건 (F12 → Console 탭 확인)
  • 반응형 — 화면 크기를 줄여도 깨지지 않는지
  • 라이트·다크 모드 둘 다 정상 작동
  • 새로고침해도 방금 작업 내용이 그대로 남아있는지
실제로 있었던 AI 실수 — 검증이 왜 필요한가

이 도구를 만드는 과정에서 실제로 AI가 이렇게 틀렸습니다.

AI가 "대기시간과 만족도가 함께 움직입니다"라고 썼지만, 실제 상관계수는 −0.94였습니다. 즉 대기시간이 길수록 만족도는 낮아진다는 뜻인데, 문장은 정반대로 읽혔습니다. AI가 만든 문장에 "미검증" 표시가 붙는 이유입니다 — 사람이 원본 수치를 한 번 더 봐야 합니다.
