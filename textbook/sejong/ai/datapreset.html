3 복원 결과

1 사용 절차

  1. ① 가명화 탭에서 원문을 붙여넣거나 .txt/.csv 파일을 불러온 뒤 [개인정보 탐지 실행]을 누릅니다.
  2. 탐지 결과를 항목별로 검토하고, 필요 없는 항목은 체크를 해제하거나 누락된 항목은 직접 추가한 뒤 [가명화 실행]을 누릅니다. 결과 텍스트를 복사해 LLM에 붙여넣고, 매핑표(.json)는 반드시 다운로드해 로컬에 보관합니다.
  3. LLM 분석이 끝나면 ② 복원 탭에 결과물을 붙여넣고 매핑표(같은 세션이면 자동, 아니면 업로드)로 [실명 복원 실행]을 눌러 실명 문서로 되돌립니다.

2 네트워크 전송 0건 — 직접 확인하는 방법

본 도구는 외부 서버·CDN·API 호출이 전혀 없는 싱글파일 HTML입니다. 모든 탐지·치환·복원은 이 브라우저 탭의 메모리 안에서만 실행됩니다.

  1. 브라우저 개발자도구를 엽니다 (Windows: F12 또는 Ctrl+Shift+I / Mac: Cmd+Option+I).
  2. Network(네트워크) 탭을 클릭합니다.
  3. 이 페이지를 새로고침하거나 가명화·복원 기능을 사용해 봅니다.
  4. 목록에 어떤 요청도 추가되지 않는지 확인합니다 (파일을 file://로 직접 열었을 때 문서 자체 요청 1건 정도만 보일 수 있으며, 그 외 API·이미지·폰트 요청은 없어야 정상입니다).

3 한계와 책임

  • 정규식 패턴 기반 탐지이며 완전 자동 탐지를 보장하지 않습니다. 반드시 리뷰 화면에서 직접 확인하세요.
  • 부서·직급·나이 조합 등 준식별자와 업무상 비밀·미공개 정책 정보는 자동 탐지 대상이 아닙니다 — 사용자가 직접 판단해 커스텀 단어로 추가해야 합니다.
  • 본 도구는 보조 수단이며, 변환 결과물의 최종 확인과 사용 책임은 사용자에게 있습니다.
  • ⚠ 매핑표 파일(.json/.csv)에는 실명이 담겨 있습니다. LLM에 업로드하지 말고 로컬에만 보관하세요.
  • 새로고침하면 세션 메모리의 매핑표가 사라집니다 — 복원이 필요하면 반드시 매핑표 파일을 먼저 다운로드하세요.
