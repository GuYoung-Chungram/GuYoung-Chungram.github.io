A. 구글폼 안의 Gemini에 넣을 프롬프트 (기본 방법)

제미나이 앱이 아니라 구글폼(forms.google.com) 화면 안의 Gemini에 붙여넣으세요. 폼이 바로 만들어집니다.
B. A가 잘 안 될 때 — 설문지+응답 시트 자동 생성 스크립트 (대체 방법)위 설문 내용과 똑같이 맞춰진 완성 코드입니다. AI가 코드를 새로 쓰게 하지 말고 이 코드를 그대로 쓰세요. 구글폼과 응답용 스프레드시트가 연결된 채로 한 번에 만들어집니다.
  1. script.google.com 접속 → 새 프로젝트
  2. 기존 코드를 모두 지우고 아래 코드를 복사해 붙여넣기 → 저장
  3. 상단 함수 선택칸에서 createPreSurvey 선택 → 실행
  4. 권한 요청이 뜨면 허용 (“확인되지 않은 앱” 경고는 내가 만든 코드라 뜨는 정상 화면: 고급 → 이동)
  5. 하단 실행 로그에서 폼 링크·편집 링크·응답 시트 링크 확인
주의 실행은 한 번만 하세요. 다시 실행하면 폼과 시트가 한 벌 더 만들어집니다. 오류가 나면 코드를 지우고 이 칸의 코드를 다시 복사해 붙여넣어 보세요.
