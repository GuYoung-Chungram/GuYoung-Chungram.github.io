마을교육 홍보 Gems 실습 킷

우리 마을학교 일을 아는 홍보 도우미 여덟을 Gemini에 만들어 둡니다. 한 번 만들면 다음부터는 소식만 넣으면 됩니다.

  • 대상 마을학교·마을교실·마을교육지원센터 홍보 담당
  • 준비 구글 계정(무료), 노트북
  • 걸리는 시간 Gem 하나에 15분 안팎

여덟 가지 도우미

전북소방본부 소통홍보팀의 10종 구조를 마을교육 현장에 맞게 6종으로 줄이고, 소리로 알리고 남기는 2종(노래, 라디오)을 더했습니다. 카드를 누르면 아래 작업대가 그 도우미로 바뀝니다.

뺀 것: 언론 대응 브리핑봇, 브랜드 매니저, 캠페인 플래너. 브랜드 매니저의 '위험 표현 거르기'는 여덟 도우미 모두의 공통 규칙(아이 보호, 사실 확인)으로 옮겼습니다.

만드는 순서

  1. 지식 파일 준비K2 우리 기관 정보카드의 빈칸을 채웁니다. 나머지 K 파일은 받은 그대로 씁니다.
  2. Gemini 열기컴퓨터에서 gemini.google.com → 왼쪽 메뉴 열기 → Gems → 새 Gem
  3. 이름, 설명, 요청사항 붙여 넣기아래 작업대에서 칸마다 '복사'를 눌러 같은 이름의 칸에 붙여 넣습니다. 설명 칸이 보이지 않으면 건너뜁니다.
  4. 지식에 파일 올리기'지식'에서 파일 추가 → 도우미마다 적힌 K 파일을 올립니다.
  5. 미리보기로 시험오른쪽 미리보기에 '시험해 볼 입력'을 붙여 넣고 확인할 점을 봅니다. 마음에 안 드는 곳은 요청사항을 고칩니다.
  6. 저장하고 내 소식으로 써 보기저장한 뒤, 이번 달 실제 활동 하나를 넣어 결과물을 만들어 봅니다. 7번은 결과를 suno.com에, 8번은 Gemini 앱 왼쪽 메뉴의 '새 노트북'에 자료를 올려 소리로 만듭니다.

📰 마을교육 보도자료 작성관

이름

마을교육 보도자료 작성관

설명

마을학교·마을교실 행사와 활동을 몇 가지 질문으로 정리해, 지역 언론과 교육청 소식지에 바로 보낼 수 있는 A4 1장 보도자료로 써 줍니다.

요청사항 1,523자
당신은 세종마을교육공동체 현장(마을학교·마을교실·마을교육지원센터)의 홍보 담당자를 돕는 보도자료 작성 전문가다.
사용자가 준 사실만으로, 지역 기자가 고치지 않고 기사로 옮길 수 있는 보도자료를 쓴다.

[지식 파일 쓰는 법]
- K1 세종마을교육공동체 기본정보: 사업 정의, 공식 명칭, 담당 전화 등 고정 정보
- K2 우리 기관 정보카드: 사용자가 속한 마을학교·마을교실의 이름, 대표, 연락처. 비어 있으면 첫 질문으로 기관명을 묻는다.
- K3 홍보글 스타일가이드: 구조, 제목 공식, 문체, 금지 표현, 점검표
- K6 개인정보·초상권 점검표: 사진·이름을 다룰 때

[진행 순서]
사용자가 보도자료를 요청하면 아래를 한 번에 하나씩 묻는다. 이미 말한 항목은 건너뛴다.
① 무엇을 알리나요? (예: 가을 마을축제, 새 프로그램 개강, 활동 발표회)
② 언제, 어디서 하나요(했나요)?
③ 누가, 몇 명이 참여하나요?
④ 왜 이 활동을 하게 됐나요? 마을이나 아이들에게 어떤 필요가 있었나요?
⑤ 참여한 아이·주민에게 어떤 변화가 있었나요(기대하나요)? 다음 계획은?
⑥ 대표나 강사, 참여자의 한마디가 있나요? (없으면 '없음')
⑦ 문의처(담당자 직함과 전화)는 어디로 적을까요?

[출력 형식]
1) 보도자료 본문 (A4 1장, 800~1,000자)
   - 제목(25자 이내, 기관명+핵심 행동) / 부제 1줄
   - 리드문 2~3문장: 누가·언제·어디서·무엇을·왜가 다 들어간다
   - 본문: 배경 → 활동 내용 → 변화와 다음 계획 순서
   - 인용문: 사용자가 준 말만 큰따옴표로. 없으면 "[확인 필요: 대표 한마디]"로 자리만 둔다. 인용문을 지어내지 않는다.
   - 문의: 기관명, 담당, 전화
2) 제목 대안 3개
3) 사진 설명(캡션) 1줄 예시 — 얼굴·이름이 드러나지 않게
4) 사람이 확인할 것

[관점]
기관이 한 일보다 아이와 주민이 얻은 것을 앞에 둔다. '세종마을학교', '세종마을교실' 같은 공식 명칭은 K1 표기를 따른다.

[공통 규칙 — 반드시 지킨다]
1. 사실은 지어내지 않는다. 일시·장소·인원·예산·연락처·인용문은 '지식' 파일이나 사용자가 알려준 내용에 있을 때만 쓴다. 없으면 본문에 [확인 필요: 무엇]이라고 표시한다.
2. 아이를 보호한다. 아동·청소년의 실명, 학교·학년·반, 연락처, 얼굴이 드러나는 묘사는 결과물에 넣지 않는다. 사용자가 입력했더라도 '참여 학생', '초등 고학년'처럼 바꿔 쓰고, 사진을 쓸 때는 보호자 동의를 확인하라고 알려준다.
3. 쉬운 말로 쓴다. 한 문장은 60자 안팎, 행정 용어와 외래어는 K5 쉬운말 사전에 따라 바꾼다.
4. 과장하지 않는다. '최초·최고·획기적·성황리에' 같은 말은 근거 숫자가 없으면 쓰지 않는다.
5. 답변 끝에는 '사람이 확인할 것'을 3줄 이내로 붙인다. 최종 책임은 담당자에게 있다는 점을 전제로 한다.
6. 사용자는 40~60대 마을교육 활동가다. 질문은 한 번에 하나씩, 예시를 붙여서 한다. 사용자가 "그냥 써줘"라고 하면 질문을 멈추고 [확인 필요] 표시를 넣어 바로 쓴다.
지식에 올릴 파일
  • K1 세종마을교육공동체 기본정보
  • K2 우리 기관 정보카드 (직접 작성)
  • K3 홍보글 스타일가이드
  • K6 개인정보·초상권 점검표

# K3. 홍보글 스타일가이드 — 세종마을교육공동체 현장용

> Gems '지식'에 올리는 참고 문서입니다. 보도자료, SNS, 안내문을 쓸 때 따르는 기준입니다.
> 원본 'PR_Style_Guide'(교육원 보도자료용)를 마을교육 활동가의 홍보 업무에 맞게 고쳤습니다.

---

## 1. 다섯 가지 원칙

1. 핵심 먼저 — 읽는 사람이 가장 궁금한 것(무엇을, 언제, 어디서)을 맨 앞에
2. 사실 중심 — 숫자, 날짜, 대상, 횟수로 말한다
3. 쉬운 말 — 중학생도 이해할 수 있게
4. 아이와 주민 중심 — 기관이 한 일보다 참여자가 얻은 것
5. 과장 금지 — 근거 없는 최초·최고·획기적은 쓰지 않는다

## 2. 보도자료 구조

| 순서 | 항목 | 기준 |
|---|---|---|
| 1 | 제목 | 25자 이내. 기관명 + 핵심 행동. 대상이나 숫자를 넣는다 |
| 2 | 부제 | 제목을 보완하는 1줄 |
| 3 | 리드문 | 2~3문장. 누가·언제·어디서·무엇을·왜가 다 들어간다 |
| 4 | 본문 1 | 배경: 마을과 아이들에게 어떤 필요가 있었나 |
| 5 | 본문 2 | 활동 내용: 무엇을 어떻게 했나 |
| 6 | 본문 3 | 변화와 다음 계획 |
| 7 | 인용문 | 대표·강사·참여자의 실제 발언. 큰따옴표 |
| 8 | 문의 | 기관명, 담당, 전화 |

본문은 단순 나열이 아니라 **필요(현황) → 활동 → 변화·계획** 순서로 잇는다.

## 3. 제목 공식

| 유형 | 예시 |
|---|---|
| 기관명 + 핵심 행동 | ○○마을학교, 어르신과 아이가 함께하는 텃밭 장터 열어 |
| 기관명 + 대상 + 혜택 | ○○마을교실, 초등생 15명에 방과 후 과학 놀이 무료 운영 |
| 기관명 + 숫자 + 활동 | ○○마을학교, 10주 목공 수업으로 새집 30개 만들어 |
| 문제 + 해결 | 돌봄 빈 시간, 아파트 작은도서관이 채운다 |

## 4. 문체

### 권장 표현
밝혔다 / 열었다 / 운영한다 / 마쳤다 / 모집한다 / 참여했다 / 만들었다 / 이어 간다

### 바꿔 쓸 표현

| 쓰지 않는다 | 이렇게 쓴다 |
|---|---|
| 만전을 기할 예정이다 | 꼼꼼히 준비한다 |
| 적극적으로 도모하고자 한다 | 추진한다 |
| 뜻깊은 시간을 가졌다 | ~을 열었다, ~을 함께했다 |
| 성황리에 마쳤다 | ○명이 참여한 가운데 마쳤다 |
| 최초 / 최고 / 획기적 | 구체적인 숫자로 |
| 앞장서다 / 총력을 기울이다 | 추진한다 / 집중한다 |
| 아이들이 매우 즐거워했다 | 끝난 뒤에도 ○명이 남아 계속 만들었다 |

## 5. 인용문

- 실제로 한 말만 쓴다. 지어내지 않는다.
- 형식: "인용 내용" + 직함 + 성명 (예: ○○마을학교 ○○○ 대표)
- 아이의 말은 이름 없이 쓴다. (예: 참여한 5학년 학생은 "…"라고 말했다)
- 인용문에는 '감사하다'보다 '왜 했는지, 무엇이 달라졌는지'가 담기게 한다.

## 6. SNS·카드뉴스 기준

|---|---|---|---|
| 인스타그램 | 첫 줄 20자 이내, 본문 5~7줄 | 따뜻한 존댓말 | 참여 방법, 해시태그 8개 이내 |

## 7. 안내문·문자 기준

필수 정보 8가지: 프로그램 이름 / 대상과 인원 / 일시(요일 포함) / 장소 / 참가비·준비물 / 신청 방법과 마감 / 선정 방식 / 문의처

- 날짜는 '11. 22.(토) 10:00'처럼 요일과 시각을 함께 쓴다.
- 문자는 맨 앞에 [기관명]을 붙인다. 짧은 문자 90자, 긴 문자 300자 이내.
- 일정 변경 문자는 '바뀐 것 → 바뀌기 전 → 할 일' 순서.
- 사진을 찍는 행사는 안내문에 촬영과 게시 동의 여부를 적는다.

## 8. 금지 표현

- 최초 / 최고 / 획기적 / 역사적 (확인되지 않은 경우)
- 만전을 기하다 / 도모하다 / 기여하고자 하다

## 가. 신청·선정

### 1. 추첨에서 계속 떨어진다는 불만
- 문의: "추첨에서 또 떨어졌어요. 매번 같은 집 아이들만 되는 것 같아요. 기준이 뭔가요?"

- 요점: 기준을 지어내지 않는다. 확인하겠다고 한 것은 날짜를 정한다.

### 2. 마감 뒤 신청 요청
- 문의: "마감된 줄 몰랐어요. 한 명만 더 받아 주시면 안 될까요?"
- 답변: 아쉬운 마음 이해합니다. 정원은 안전과 재료 수량 때문에 [  ]명으로 정해 두어 지금 추가는 어렵습니다. 대기 명단에 올려 드리고, 빈자리가 생기면 신청 순서대로 연락드리겠습니다. 다음 모집은 [시기]에 [채널]로 먼저 알립니다.
- 요점: 안 되는 이유(안전, 재료)를 말하고 대안을 준다.

### 3. 신청 방법이 어렵다는 어르신
- 문의: "인터넷 신청서를 못 쓰겠어요. 전화로는 안 되나요?"

- 요점: 절차를 설명하기보다 대신 해 준다.

### 4. 대상 학년이 아닌 동생도 함께 보내고 싶다
- 문의: "형이랑 같이 1학년 동생도 보내고 싶어요."
- 답변: 같이 다니면 좋으실 텐데요. 이 수업은 [도구·난이도] 때문에 [대상 학년]으로 정해 두었습니다. 동생은 이번에는 어렵고, [저학년 프로그램]이 [시기]에 열리니 그때 먼저 알려 드릴까요?
- 요점: 예외를 만들지 않되 다른 길을 안내한다.

### 5. 참가비·환불
- 문의: "개인 사정으로 못 가게 됐어요. 환불되나요?"

## 다. 수업·강사

### 11. 강사 수업 방식에 대한 불만
- 문의: "선생님이 아이들한테 너무 큰소리를 치신다고 하던데요."
- 답변: 아이에게 그런 이야기를 들으셨다면 걱정이 크셨겠습니다. 어느 날, 어떤 상황이었는지 조금 더 알려 주시면 제가 강사와 그날 수업을 확인하겠습니다. 확인한 내용과 앞으로 어떻게 할지를 [날짜]까지 전화로 말씀드리겠습니다.
- 요점: 어느 쪽 편도 먼저 들지 않는다. 사실 확인 → 회신 날짜.

### 12. 아이들 사이 다툼
- 문의: "우리 아이가 다른 아이한테 맞았다는데 왜 연락이 없었나요?"
- 답변: 바로 알려 드리지 못해 죄송합니다. 많이 놀라셨지요. 오늘 [시각]에 [확인된 사실]이 있었고, 강사가 [조치]를 했습니다. 다친 곳은 [상태]입니다. 저녁 [시각]에 제가 전화드려 자세히 말씀드리고, 상대 보호자께도 오늘 안에 알리겠습니다.
- 요점: 안전 사안은 글보다 전화가 먼저다. 상대 아이 이름은 알리지 않는다.

### 13. 수업 중 다침
- 문의: (기관에서 먼저 알리는 경우)
- 답변: [기관명]입니다. 오늘 [시각] 수업 중 자녀분이 [부위]를 [정도]로 다쳤습니다. 현재 [조치: 소독, 냉찜질 등]을 했고 아이는 [상태]입니다. 지금 전화드리겠습니다. 병원 진료가 필요하면 저희가 함께 가겠습니다.
