STEP 01

구글 스프레드시트 템플릿 생성

✓
  1. 본인 구글 드라이브 접속 ➔ 새 구글 스프레드시트 생성
  2. 하단 시트 탭 이름을 prompts로 변경 (소문자 필수)
  3. 파일 ➔ 가져오기 ➔ 업로드 탭에서 다운로드받은 sample-prompts.csv 선택
  4. 가져오기 위치: '현재 시트 바꿈' 선택 후 데이터 가져오기 클릭
💡 텍스트를 그냥 복사-붙여넣기 하지 마시고 파일 가져오기를 사용해야 프롬프트 쉼표(,)가 분절되지 않습니다.
STEP 02

Google Apps Script 코드 연동

✓
  1. 생성한 구글 시트 상단 메뉴 ➔ 확장 프로그램 ➔ Apps Script 클릭
  2. 기존 Code.gs 기본 코드를 전체 삭제
  3. 다운로드한 Code.gs 파일의 스크립트 전체를 복사하여 붙여넣기
  4. 상단 저장 (Ctrl+S / Cmd+S) 클릭
STEP 03

웹 앱(Web App) 배포 및 URL 복사

✓
  1. 우측 상단 배포 ➔ 새 배포 클릭
  2. 유형 선택(⚙️) ➔ 웹 앱 선택
  3. 실행 계정: 나 (My Account)
  4. 액세스 권한: 모든 사용자 (Anyone) ⚠️ (핵심 설정!)
  5. 배포 클릭 ➔ 경고 발생 시 고급 ➔ 안전하지 않음으로 이동 ➔ 허용
  6. 생성된 웹 앱 URL (https://script.google.com/macros/s/...)을 복사
⚠️ 액세스 권한을 '모든 사용자'로 지정해야 프론트엔드 앱에서 로그인 없이 데이터 연동이 가능합니다.
STEP 04

index.html 연동 & 최종 테스트

✓
  1. index.html 파일 편집기(메모장 또는 IDE)로 열기
  2. 상단 script 영역의 APPS_SCRIPT_URL 변수에 본인 복사 URL 대입:
var APPS_SCRIPT_URL = 'https://script.google.com/macros/s/YOUR_URL/exec';
  1. 저장 후 index.html을 브라우저로 실행
  2. 상단 칩에 "구글시트 연동됨" 표시를 확인하면 완벽 성공! 🎉
